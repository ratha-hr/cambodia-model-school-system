## 🌟 លក្ខណៈពិសេសចម្បង (Key Features)

ប្រព័ន្ធនេះត្រូវបានបង្កើតឡើងដោយការអាន និងទាញយកទិន្នន័យយ៉ាងល្អិតល្អន់ចេញពីឯកសារ **`7A.xlsm`** ដោយបំប្លែងពី Macro Excel ទៅជាគេហទំព័រ Web App ទំនើប Responsive 100% ដំណើរការបានគ្រប់ឧបករណ៍ (កុំព្យូទ័រ, Tablet, ទូរស័ព្ទដៃ) និងស្របតាមបទដ្ឋានសាលារៀនគំរូរបស់ក្រសួងអប់រំ យុវជន និងកីឡា៖

### 1. 📊 ផ្ទាំងគ្រប់គ្រងទិន្នន័យគរុកោសល្យ (Executive Dashboard)
- បង្ហាញសូចនាករគន្លឹះ (KPIs) របស់ថ្នាក់រៀន៖ ចំនួនសិស្សសរុប (៥៤ នាក់, ស្រី ២៨ នាក់), អត្រាជាប់, មធ្យមភាគថ្នាក់ (លើ ៥០ និងលើ ១០)។
- តាមដានសិស្សរៀនយឺតដែលត្រូវការបំប៉ន និងសិស្សងាយរងគ្រោះ (ក្រីក្រ, កំព្រា, ពិការ, អាហារូបករណ៍)។
- តារាងចំណាត់ថ្នាក់សិស្សពូកែ Top 5 ប្រចាំខែ និងការបែងចែកនិទ្ទេសរួម (A, B, C, D, E, F)។

### 2. 🏛️ ការងាររដ្ឋបាល និងបន្ទុកថ្នាក់រៀន (Classroom Management)
- **ក្រុមប្រឹក្សាយុវជន និងអនុសាខាទាំង ៦ (Sheet Co & Y)៖**
  - ប្រធានថ្នាក់: លី គឹមហេង, អនុប្រធានទី ១: ហ៊ាន អូនវឌ្ឃនៈ, អនុប្រធានទី ២: ទៀង រក្សា។
  - អនុសាខាទី ១ ដល់ ទី ៦ ដែលមានសមាសភាពសិស្ស និងតួនាទីជាក់លាក់។
- **បញ្ជីឈ្មោះគ្រូបង្រៀនតាមមុខវិជ្ជា (Sheet T)៖**
  - គ្រូបង្រៀនទាំង ១២ មុខវិជ្ជា ជាមួយលេខទូរស័ព្ទទំនាក់ទំនង និងប៊ូតុងចុចខលចេញផ្ទាល់។
- **បញ្ជីសារពើភ័ណ្ឌ និងទ្រព្យសម្បត្តិថ្នាក់រៀន (Sheet F)៖**
  - តាមដានតុ, កៅអី, ក្តារខៀន, ផ្ទាំងរូបភាព, រូបមន្ត, ពាក្យស្លោក, និងរំយោលទ្វារបង្អួច។
- **កាតាឡុកអាហារូបត្ថម្ភ និងកម្ពស់/ទម្ងន់/BMI (Sheet Food)៖**
  - តាមដានសុខភាពសិស្ស និងការចាត់ថ្នាក់ទម្ងន់សមស្រប កង្វះអាហារូបត្ថម្ភ និងលើសទម្ងន់។
- **មូលនិធិថ្នាក់រៀន និងថវិកាតុបតែង (Sheet1 (2))៖**
  - តាមដានការចូលរួមរបស់អាណាព្យាបាលសិស្ស (ប្រមូលបាន ១,៧២០,០០០ រៀល ពី ៣៥+ គ្រួសារ)។
- **ផែនការសកម្មភាពប្រចាំសប្តាហ៍ និងប្រចាំឆ្នាំ (Sheet Table1 & Table2)៖**
  - ផែនការបែងចែកការងារប្រចាំថ្ងៃ និងផែនការប្រតិបត្តិ ១០ ខែ នៃឆ្នាំសិក្សា។

### 3. 📑 តារាងស្រង់ពិន្ទុ និងគណនាចំណាត់ថ្នាក់តាមរូបមន្តក្រសួង (Excel Spreadsheet Grid)
- គណនាពិន្ទុស្វ័យប្រវត្តិតាមមេគុណ MoEYS សម្រាប់មុខវិជ្ជាទាំង ១២៖
  - ភាសាខ្មែរ (ពិន្ទុ ១០០, មេគុណ ២)
  - គណិតវិទ្យា (ពិន្ទុ ១០០, មេគុណ ២)
  - រូបវិទ្យា, គីមី, ជីវវិទ្យា, ផែនដី, ប្រវត្តិ, ភូមិ, សីលធម៌, អង់គ្លេស, អប់រំកាយ, កសិកម្ម (ពិន្ទុ ៥០, មេគុណ ១)
- មធ្យមភាគលើ ៥០ = ពិន្ទុសរុប ÷ មេគុណសរុប (១៤)។
- ចំណាត់ថ្នាក់ស្វ័យប្រវត្ត (Rank 1, 2, 3...) និងនិទ្ទេស A (≥៩០%), B (≥៨០%), C (≥៧០%), D (≥៦០%), E (≥៥០%), F (<៥០%)។
- គាំទ្រការបិទភ្ជាប់ (Paste) ទិន្នន័យពី Excel ដោយផ្ទាល់។
- ប្តូរមើលបានគ្រប់ខែ, ឆមាសទី ១, ឆមាសទី ២ និងលទ្ធផលបញ្ចប់ឆ្នាំ (ដំណាច់ឆ្នាំ)។

### 4. 📇 បញ្ជីប្រវត្តិរូបសិស្សពិស្តារ (Student Registry)
- បញ្ជីសិស្សទាំង ៥៤ នាក់ ពេញលេញដោយអត្តលេខ, ថ្ងៃខែឆ្នាំកំណើត, ទីកន្លែងកំណើត, អាសយដ្ឋាន, ព័ត៌មានឪពុកម្តាយ, មុខរបរ, និងលេខទូរស័ព្ទ។
- ផ្ទាំងកែសម្រួល បន្ថែម ឬលុបទិន្នន័យសិស្ស។
- វាយតម្លៃ ៤ វិស័យ (សីលធម៌, សុខភាព, បង្កបង្កើនផល, សោភ័ណ)។

### 5. 📅 កត់វត្តមានសិស្ស និងអវត្តមានគ្រូ (Attendance Tracker)
- កត់វត្តមានប្រចាំថ្ងៃ (វត្តមាន, មានច្បាប់, អត់ច្បាប់, មកយឺត)។
- ស្រង់សរុបប្រចាំខែ និងប្រចាំឆ្នាំដោយស្វ័យប្រវត្ត។

### 6. 🏆 ប័ណ្ណសរសើរ និងព្រឹត្តិបត្រពិន្ទុផ្លូវការ A4 (Report Cards & Certificates)
- បោះពុម្ពប័ណ្ណសរសើរសិស្សឆ្នើម Top 5 មានក្បាច់រចនារបស់ក្រសួងអប់រំ និងត្រាសាលា។
- ព្រឹត្តិបត្រពិន្ទុបុគ្គល (សៀវភៅតាមដានការសិក្សា A4) មានហត្ថលេខាគ្រូបន្ទុកថ្នាក់ និងនាយកសាលា។

## ☁️ ការប្រើប្រាស់ GitHub ជា Database (GitHub Cloud Database)

ប្រព័ន្ធនេះត្រូវបានរចនាឡើងដើម្បីប្រើប្រាស់ **GitHub Repository ជា Cloud Database** ដោយផ្ទាល់ តាមរយៈ GitHub REST API v3៖
1. **ទិន្នន័យមាន Version Control ជានិច្ច៖** រាល់ពេលគ្រូ Sync ទិន្នន័យ ប្រព័ន្ធនឹងបង្កើត Commit មួយនៅលើ GitHub អាចមើលប្រវត្តិ Version History បានគ្រប់ពេល។
2. **Offline-First៖** ដំណើរការបានទោះបីដាច់អ៊ីនធឺណិត (រក្សាទុកលើ Browser LocalStorage) ហើយ Sync ទៅ GitHub នៅពេលមានអ៊ីនធឺណិតវិញ។
3. **របៀបតភ្ជាប់ Token៖**
   - ចូលទៅកាន់ **Settings > កំណត់ GitHub DB** ឬចុចលើប៊ូតុង **GitHub Database** នៅជ្រុងខាងស្តាំលើ។
   - បញ្ចូល GitHub Personal Access Token (PAT) ដែលមានសិទ្ធិ `repo`។
   - ចុច **Sync ទៅកាន់ GitHub** ឬ **ទាញយកពី GitHub (Pull)**។

## 🚀 របៀប Hosting ទៅកាន់ Vercel (Vercel Deployment)

ដោយសារកូដត្រូវបាន Push ឡើងទៅកាន់ GitHub Repository [https://github.com/ratha-hr/cambodia-model-school-system](https://github.com/ratha-hr/cambodia-model-school-system) រួចរាល់ ការ Hosting ទៅ Vercel គឺចំណាយពេលមិនដល់ ២ នាទីឡើយ៖

### វិធីទី ១៖ តាមរយៈគេហទំព័រ Vercel (ងាយស្រួលបំផុត)
1. ចូលទៅកាន់ [vercel.com](https://vercel.com) ហើយ Login ជាមួយគណនី GitHub របស់អ្នក។
2. ចុចប៊ូតុង **Add New...** > **Project**។
3. ស្វែងរក និងចុច **Import** លើ Repository `cambodia-model-school-system`។
4. Vercel នឹងរៀបចំ Build Command (`npm run build`) និង Output Directory (`dist`) ដោយស្វ័យប្រវត្ត។
5. ចុច **Deploy** រង់ចាំប្រមាណ ២០ វិនាទី! គេហទំព័ររបស់អ្នកនឹងដំណើរការលើអនឡាញជាសាធារណៈ។

### វិធីទី ២៖ តាមរយៈ Terminal (Vercel CLI)
```bash
# ដំឡើង Vercel CLI (បើមិនទាន់មាន)
npm i -g vercel

# ដាក់ឱ្យដំណើរការ
vercel --prod
```
